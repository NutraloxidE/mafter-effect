# RG-20260704-03 — Browser multi-frame VO + OpenCV WASM

## 親の目的
ブラウザ内で可能な限り高精度な Motion Track。ユーザー承認方針:
- マルチフレーム追跡
- OpenCV WASM（既存 `public/motion-track/opencv/`）
- Fable 相談しつつ Cursor が実装

## 確定事項
- 現行 opencv.js@1.2.1 には **solvePnP / findEssentialMat / triangulatePoints が無い**（実測）。使えるのは `goodFeaturesToTrack` + `calcOpticalFlowPyrLK` 等。
- Walk モードは FOE/発散フローで「甘いが動く」。AE 級ではない。
- §5/INV 非変更、editor-only、player.js 非同梱。

## 親の実装方針（レビューして）
1. OpenCV は **KLT / 特徴検出のみ**継続利用
2. **マルチフレームトラック管理**（track id → フレーム列の (x,y)）
3. キーフレーム間で **DLT 三角測量**（純 TS）
4. 後続フレームは **DLT-PnP / 簡易 PnP**（純 TS）でポーズ更新
5. 任意: ポーズのみの軽い平滑 / 再三角測量
6. UI: Walk をこの経路に置き換え or 「Walk (高精度)」

## 問い
1. 上記でよいか。techstark OpenCV（solvePnPRansac あり・~10MB）へ差し替えるべきか
2. キーフレーム間隔・トラック最低長・BA の要否
3. Comp 27 受け入れ条件の数値
