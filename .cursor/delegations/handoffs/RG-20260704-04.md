# RG-20260704-04 — トラックマット: text マットで solid 全体が透明

## 親の目的（1–3 文）
Solid の直上に Text をマット源として置いたとき、ソリッド全体が透明になる不具合の**根本原因**を確定し、live 性を保ちつつ INV-2（preview≡export）を満たす**修整方針を 1 案に固定**する。親は戻り後に plan を確定し実装する。

## 確定事項
- §5.4f `trackMatteMode?: "alpha"|"alphaInverted"|"luma"|"lumaInverted"` は実装済み（ユーザー承認済み）。
- ペアリング: zOrder スタックの直上（フレーム非依存）。非可視は空マット（再バインドしない）。
- 塗り側に `trackMatteMode`、マット源は直上レイヤー（ID 参照なし）。
- 初版実装: SVG `<mask>` + `foreignObject` にマット DOM を入れ、塗り host に `mask-image: url(#tm-…)`。
- ユーザー報告: **Solid の上に Text をマットにするとソリッド全体が透明**。
- 応急修正済み（未検証の穴あり）: SVG mask をやめ、fillHost `isolation:isolate` + マット子に `mix-blend-mode: destination-in`（inverted は `destination-out`）。
- unit: `test/trackMatte.test.ts` 13 PASS。verify: `verify-track-matte.mjs` は DOM 配線中心で、**文字形状に切り抜かれたことの画素証明が弱い**（非ゼロ画素なら PASS）。

## 未決・委任したい問い
1. **初版が全体透明になった主因**は foreignObject-in-mask で確定か？ 他要因（ペアリング誤り・空マット経路・zOrder・Track Matte を塗りではなくマット側に付けた UX）の寄与は？
2. **destination-in 方式**は AE alpha matte として正しいか？ text のレイヤー構造（外側 div + 内側テキスト）で「グリフ以外が透明」になり全体透明に見えるケースはあるか？
3. **getComputedStyle(mixBlendMode) が `"normal"` を返した**一方 `style.mixBlendMode` / `data-track-matte-blend` は `destination-in` — これはブレンド未適用の兆候か、計測アーティファクトか？
4. **export（foreignObject キャプチャ）**で destination-in が落ちるリスクと、正準を「live blend」vs「canvas `applyTrackMatte`」のどちらにすべきか（INV-2）。
5. 推奨アーキテクチャを **1 案**に固定し、却下案と受け入れ条件（verify の画素ゲート）を書け。
